# Plasmid Defense Network

[![Launch App](https://img.shields.io/badge/Launch_App-3b82f6?style=for-the-badge&logo=rocket&logoColor=white)](https://leightonpayne.github.io/plasmid_network/)

An interactive web application for exploring the global plasmidome and visualizing the distribution of defense systems, anti-defenses, and many other features.

## Usage

**Explore the network** by using the mouse to pan and zoom. **Change coloring** by using the sidebar to select different mapping attributes. **Select a plasmid** by clicking on a node to view its genome map. **View the underlying data** by toggling the "Show data table" button in the top-left corner. **Identify fascinating patterns** to investigate in your own research projects.

## Run app locally

```bash
git clone <repo-url>
cd plasmid_network
npm install
npm run dev
# This should open the app in your browser at http://localhost:5173/plasmid_network/
```
